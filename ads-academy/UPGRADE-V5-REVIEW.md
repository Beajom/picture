## 已交付

1. **28天分日验收**：28道独立的作业清单，每天分别填写3项证据，不再仅靠泛泛的字数判断。
2. **规则检查与正式审核分层**：第1-3天检查公式和输入，第4-28天核对专属证据项、日期、关键数字与分析完整性。规则初审通过并不意味着结论正确。
3. **AI审核入口**：Supabase Edge Function `academy-review`（`verify_jwt=true`）已部署。前端要求登录，调用服务端 OpenAI Responses API，返回百分制及4项分数、问题与整改清单。AI仅获取用户点击审核后提交的**作业文字、指标、附件名称**，不会自动读取附件原始字节。
4. **使用前需配置密钥**：此环境未验证到可用 `OPENAI_API_KEY`。需要由项目管理员在 Supabase Dashboard → Edge Functions → Secrets 中配置 `OPENAI_API_KEY`（可选 `OPENAI_REVIEW_MODEL`，默认 `gpt-4.1-mini`）。**禁止把密钥填在网页或公开 GitHub 里**。未配置时前端提示，并保留复制到 ChatGPT / 实际老师的审核流程；不会假装自动审核完成。
5. **真实反馈与手工登记区别**：通过正式AI接口返回的成功评分可标记 `passed`；用户自行登记的实际老师/ChatGPT反馈单独标为 `manual_reviewed`，不会伪装成自动审阅。
6. **可追溯的提交历史**：保留规则检查、AI审阅和人工反馈、整改记录；重新编辑作业后需再次审核。
7. **独立私人附件仓库**：Supabase 创建私有 Storage bucket `academy-homework-private`，每位用户只能操作自己 `auth.uid()` 文件夹里的文件。四条 RLS 策略分别限制 SELECT/INSERT/UPDATE/DELETE，未改变旧 PPC 表。
8. **附件优先本机**：新增作业时首先保存本地 IndexedDB；登录的用户自动尝试同步私人云端，失败不会导致本地附件丢失，可手动点“同步附件到私人云端”。跨设备登录同账号后可从私人云端下载。原始广告报表仍保存在本地，不会自动上传。
9. **学习进度区分**：显示AI审核通过、人工登记通过、待审核、退回；旧版“完成”记录保留但不自动视为复核成功。
10. **更紧凑的课程页面**：仅展开当前/选中任务，其他任务可以展开或收起。每日有对应课程、实操、报表和专属评分清单。
11. **ASIN成本带入**：第1-2天可以从商品库填入实际售价、费用、汇率换算数据，但需自行核对成本口径；绝不自动拿系列广告费用当作单个子ASIN数据。
12. **报表日期过滤修正**：当筛选日期范围时，**没有有效日期**的行会被排除，页面提示受影响的行数。原始报表汇总卡明确标注与当前筛选独立。
13. **加载优化**：Excel读取库进入导入流程时才加载，避免不需要上传的课程页面承受额外资源。
14. **进度和审核备份**：旧数据、AI评分与审核意见都可以导出CSV；本机和云端记录按照更新时间选择更新记录，保留历史摘要。

## 操作

1. 在【28天学习计划】选定ASIN，打开当天任务。
2. 学完相关课时，从广告工作台找真实报表，填写数字与来源、三条验收项的依据和风险/复查。
3. 可选：上传图片/PDF/Excel证据文件，登录后会尝试保存到私人云端存储。
4. 点击“①提交规则初审”。计算错误或材料不完整会退回。
5. 规则初审完成后，点击“②AI正式审核”；若尚未配置服务端密钥，改用“复制审核材料”粘贴到 ChatGPT，并自行上传附件，或交给真实老师。
6. AI给出错误、原因、改进方案及100分制评分；需要修改则重交。人工反馈登记与AI评分分开保存。

## 限制和注意事项

- **AI不是自动审阅附件**：当前接口只有附件文件名，真实文件内容不会被自动转发给AI。需要审核附件内的细节时，应在ChatGPT中另行上传，或后续加入权限可控的服务端文件解析与引用能力。
- **未配置密钥即不能完成自动AI评分**：后台已部署但不能假装AI调用成功；页面应提供可理解的提示。
- **AI评分有误差**：即使80分以上，也不应把AI判断当成真实广告平台的确定结果。
- **商品归因仍需严谨**：SP/SB搜索词和广告位汇总不能合并为重复销售；产品组合不等于子ASIN归因。
- **旧数据库问题仍需单独处理**：此前审计报告提示13张已有 PPC 表未开启 RLS。这次为了不破坏现有系统，未擅自更改那些表。
- **真实浏览器验收待进行**：已经过脚本语法、模拟表单/成绩流转及数据库策略的测试；不代表已在用户本机实际登录、上传、AI供应商计费和多设备下载中完成端到端验收。
