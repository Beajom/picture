## 本次已实现

1. **Soju 模板兼容**：读取 SP / SB 搜索词及广告位原始数据页，跳过透视结果页；支持 Excel、CSV。
2. **空数据与单位保护**：分母为零时显示“—”；区分 SP 7天与 SB 14天归因；在界面选择不同币种和日期。
3. **报表安全隔离**：原始明细只保存在浏览器 IndexedDB；选定同一报表类型后再作分析，不重复累加搜索词和广告位。
4. **搜索词、广告位、活动诊断**：按自身定义的目标 CPA/ACOS 给出放量、核查消耗、潜力、观察等分组。判断必须由运营者复核。
5. **ASIN 单品利润模型**：售价、采购、头程、FBA、佣金、损耗、折扣、目标利润率；计算贡献利润、盈亏平衡和目标 CPA/ACOS。
6. **营业额与 TACOS**：手动输入相同期间、相同币种的完整广告花费与店铺销售额；未补齐口径时不显示完整 TACOS。
7. **SB 专用指标**：视频5秒观看/完整观看、品牌新买家、点击归因拆分，不与总销售额重复相加。
8. **自然排名**：手动添加或用标准 CSV/XLSX 导入排名快照，按 ASIN/关键词比较新旧排名。
9. **重复投放检查**：同一个搜索词跨广告活动出现时标记为待核对，不直接判定内部竞价浪费。
10. **动作管理与复盘**：记录优化建议、状态、复查日期、执行记录，支持 CSV 导出。
11. **真实数据学习**：从导入报告生成练习题，记录用户自己的答案；提供明显标识的虚拟演示数据。
12. **课题与进度**：保留现有课程和 28 天学习计划，调整情景题选项位置，减少答题位置偏差。
13. **云端记录合并**：登录远端数据与本机不一致时先保留同步恢复备份，再合并学习进度及行动。
14. **Excel 阅读器**：固定 SheetJS 官方 CDN 0.20.3。

## 真实数据操作步骤

1. 亚马逊后台导出 SP 搜索词、SP 广告位、SB 搜索词、SB 广告位报告；
2. 打开“广告数据实战 → 报表导入”，选择多个 CSV/XLSX；
3. 同名、同工作表报告会更新旧版本；不同月份保留为不同数据来源，汇总时做日期维度去重；
4. 在 ASIN 利润库录入真实费用，按需要手动关联导入报告与 ASIN；
5. 在“搜索词决策 / 广告位诊断 / 活动治理”检查建议；
6. 在“优化任务与复盘”记录执行与复查；
7. 使用“真实数据训练”或“28天学习计划”复习。

## 局限与数据口径

- Soju 提供的原始报告页只有列标题，没有广告明细行，需填入或上传真实报告后才能计算。
- 源文件如果包含多个不同店铺、币种或归因窗口，不能无条件相加。
- 真实利润计算**以用户实际录入的费用为准**，不以系统示例当作真实 Fee Preview。
- 搜索词/广告位报告不包含完整自然销量；真实 TACOS 需要完整广告花费与同期总销售额。
- 该页面**不能**自动操作 Amazon Ads 账户，不会自动出价或否定关键词。
- 领星接口状态为 `GATEWAY_REQUIRED`；SIF API 状态为 `NOT_CONFIGURED`。自动同步需要私有服务端网关、权限及真实凭据，不能把密钥写到 GitHub Pages。
- 浏览器 IndexedDB 存储的原始广告明细**不会自动跨设备同步**，清除网站数据可能导致丢失；请保存原始导出文件。
- 排名快照来自手动或导入数据，不能冒充 SIF 实时自然排名。
- 解析库使用外部 CDN 版本，若网络阻止 CDN 可先导出 CSV。

## 数据库安全需要单独处理

在项目 `Bsera` 中检查发现 13 张旧的 `public.ppc_*` 表目前未开启 RLS；Supabase 安全顾问指出这些暴露在 Data API 中的表存在未经按用户隔离的访问风险。**本次未自动执行 ALTER TABLE**，避免阻断已有的 PPC 系统。应先确认每张表的所属用户字段与历史系统依赖、建立用户隔离的 SELECT/INSERT/UPDATE/DELETE 策略，再在维护窗口安全迁移和开启 RLS。

- 官方参考：https://supabase.com/docs/guides/database/postgres/row-level-security
- Supabase 数据库安全顾问：Dashboard → Advisors → Security
