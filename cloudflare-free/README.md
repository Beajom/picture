# Amazon Supply Workbench — Free Cloudflare template

This folder is intentionally isolated from the legacy deployment template.

Resources:
- Cloudflare Worker + Static Assets
- D1 binding: `DB`
- Workers KV binding: `IMAGES`
- No R2 dependency

Deploy this subdirectory with:
https://deploy.workers.cloudflare.com/?url=https://github.com/Beajom/picture/tree/main/cloudflare-free
